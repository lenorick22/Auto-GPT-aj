# Identity theft checklist (use only if accounts are not yours)

1. Place a **fraud alert** or **credit freeze** at Equifax, Experian, and TransUnion.
2. File a report at **IdentityTheft.gov** and save the recovery plan / affidavit.
3. File a police report if needed for creditors or bureaus.
4. Dispute fraudulent accounts with bureaus **and** furnishers; include affidavit + ID + proof of address.
5. Contact fraud desks for any opened accounts; request written confirmation of closure.
6. Change passwords / enable MFA on email and financial accounts.
7. Keep a dated log in `trackers/dispute_log.csv`.

This agent can help organize documents and drafts — it cannot file freeze requests for you.
