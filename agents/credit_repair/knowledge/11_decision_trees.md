# Decision trees

## A) User says “fix my credit”
1. Pull/compare 3 reports → inventory.
2. Any not-mine/fraud? → identity theft path.
3. Any clear errors? → dispute with evidence.
4. Accurate derogs? → rebuild + optional goodwill/settlement strategy.
5. High utilization? → payment timing + payoff plan.
6. Thin file? → secured/builder/AU strategies.
7. Publish ranked NEXT_ACTIONS.

## B) Item on report
```
Is it yours?
  No → freeze? → dispute as not mine / fraud package
  Yes → Are the facts accurate?
          No → dispute-error with proof
          Yes → Is it a collection with unclear amount/owner?
                  Yes → validate
                  No → pay/settle/goodwill/rebuild path
```

## C) Need score up in 30–60 days
Focus on: eliminate lates going forward, slash utilization before statement dates, correct obvious errors, avoid new hard pulls.
Do not promise a number.

## D) Mortgage / auto shopping soon
- Get reports early; fix errors first.
- Avoid new revolving max-outs.
- Shop loans inside recognized inquiry windows.
- Ask lender which score model they use.
