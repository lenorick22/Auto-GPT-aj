# Letter strategy

## Sequencing
1. Inventory & classify first — don’t mail blind templates.
2. Identity theft / not-mine items before cosmetic goodwill asks.
3. Validation letters for unclear collections before negotiating payment when ownership/amount is uncertain.
4. Goodwill only after a stretch of repaired behavior (often 6+ on-time months), for accurate lates.
5. Keep one primary ask per letter when possible.

## Tone
- Firm, factual, polite.
- Cite the right framework lightly (FCRA investigation, validation request) without sounding like a fake “legal threat kit.”
- No profanity, no accusations you can’t support.

## Evidence discipline
- Copies only; keep originals.
- Reference attachments explicitly.
- Redact full SSN in drafts saved to chatty logs when possible (use last4).

## Channels
- Bureau online portals are fine if you save confirmations.
- Certified mail helps create a paper trail for furnishers/collectors.
- Log everything in `trackers/dispute_log.csv`.

## Follow-ups
- Mark a ~30-day response checkpoint.
- If verified wrongly, add evidence and dispute again / complain to CFPB with documentation.
- If validated and accurate, switch to payoff/settlement/rebuild planning.
